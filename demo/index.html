Payments as a filter
in a proxy you already run.

Not another proxy to put in your path — an Envoy filter. The same ext_proc interface works under Istio, Consul, Gloo and Envoy Gateway, so metering and payment become a policy rather than a new hop. The upstreams below have no payment code of their own and never learn they are being sold.

Point a real client at it

Nothing above requires this page. The gate is the public endpoint, so any x402 client can hit it. This one signs with your wallet instead of the demo's.

git clone https://github.com/0xfreak0/sui-x402-verifier && cd sui-x402-verifier

# You need testnet USDC, from faucet.circle.com (chain: Sui Testnet).
# You do not need any SUI. Payments above 0.01 USDC run gasless.
cargo run --bin x402-pay -- https://x402.suisonar.dev/graphql \
  -X POST -H 'content-type: application/json' \
  -d '{"query":"{ chainIdentifier }"}'

Or just watch it refuse you, no wallet needed:

for i in $(seq 6); do
  curl -s -o /dev/null -w '%{http_code} ' -X POST https://x402.suisonar.dev/graphql \
    -H 'content-type: application/json' -d '{"query":"{ chainIdentifier }"}'
done      # 200 200 200 200 200 402
